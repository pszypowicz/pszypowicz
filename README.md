Hey, thanks for stopping by.

I work as a cloud engineer and architect. When I spot something broken, at work or at home, I find it hard to leave it alone until I have fixed it.

I'm a terminal lover, and I enjoy home automation enough that I went and got certified by both Ampio and KNX. Most of the projects below came out of those two interests and out of making my Mac fit the way I work.

## Things I made

Most of the apps and tools install from my [Homebrew tap](https://github.com/pszypowicz/homebrew-tap), for example `brew install --cask pszypowicz/tap/cyclist`.

### macOS apps

- [MicGuard](https://github.com/pszypowicz/MicGuard) - a menu bar app that stops Bluetooth headphones from taking over the default microphone.
- [cyclist](https://github.com/pszypowicz/cyclist) - a text-only app switcher in the style of alt-tab.
- [BrightSync](https://github.com/pszypowicz/BrightSync) - copies the brightness of the built-in display to external displays over DDC/CI.
- [sequester](https://github.com/pszypowicz/sequester) - an SSH agent that keeps keys in the Secure Enclave and sets forwarding rules per key.
- [TrackpadKit](https://github.com/pszypowicz/TrackpadKit) - a trackpad gesture recognizer for AppKit, built on raw touch events.

### Terminal tools

- [pager](https://github.com/pszypowicz/pager) - macOS notifications that focus the right window on click and clear themselves, sent from a shell or a tmux hook.
- [afm-summarize](https://github.com/pszypowicz/afm-summarize) - summarizes stdin into one short sentence with Apple's on-device Foundation Models.
- [optiprime](https://github.com/pszypowicz/optiprime) - a terminal UI that keeps a directory of Azure DevOps repositories in sync.

### Home Assistant

- [ampio-homeassistant](https://github.com/pszypowicz/ampio-homeassistant) - an integration for the Ampio smart home system.
- [ampio-mqtt](https://github.com/pszypowicz/ampio-mqtt) - the async Python client that the integration uses to talk to Ampio over MQTT.
- [siipet-homeassistant](https://github.com/pszypowicz/siipet-homeassistant) - an integration for SiiPet pet health devices.
- [scene_state](https://github.com/pszypowicz/scene_state) - tracks whether a scene is active.
- [state-card-feature](https://github.com/pszypowicz/state-card-feature) - shows the entity state inside a card.

### Tooling and web

- [hugo-theme-pager](https://github.com/pszypowicz/hugo-theme-pager) - the monospace theme that my blog uses. It fits the first page load into 14 KB.
- [dotfiles](https://github.com/pszypowicz/dotfiles) - my macOS setup, managed with GNU Stow and installed by one bootstrap script.
- [claude-skills](https://github.com/pszypowicz/claude-skills) - a small plugin marketplace for Claude Code.

## Forks I maintain

These forks carry changes I use every day on top of upstream releases. I'd like each change to land upstream so the forks are no longer needed.

- [ghostty](https://github.com/pszypowicz/ghostty) - trackpad gestures that bind to any action, and a reporting mode (DEC private mode 2035) that passes gestures to terminal applications. Install with `brew install --cask pszypowicz/tap/ghostty-personal`.
- [tmux](https://github.com/pszypowicz/tmux) - turns those gesture reports into key names such as `Swipe3Left` and `PinchIn` that you can bind. Install with `brew install pszypowicz/tap/tmux-gestures`.
- [AeroSpace](https://github.com/pszypowicz/AeroSpace) - BSP-shape normalization, per-workspace normalization overrides, and a focus fix for windows restored from the Dock. Install with `brew install --cask pszypowicz/tap/aerospace-bsp`.
